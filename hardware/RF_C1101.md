# C1101 RF module for Lilka

## Compatibility
Bruce firmware, all functions of the RF app. Choose CC1101 in Config menu.

## Inventory
- CC1101 Wireless 2x4 pins module
- 20x80 prototype PCB
- female 12-pin header
- thin copper wires
- a ceramic capacitor 0.2-0.5uF (optional)
