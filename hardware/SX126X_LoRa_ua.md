# Модуль LoRa на SX126x для Lilka

Наведена інструкція підходить для модулів E22, DX-LR20, DX-LR30 і, найімовірніше, інших 12-контактних SPI-модулів LoRa.

## Сумісність
Meshtastic, Meshcore, LoRa-чат у Bruce. Мережі 433, 868 та 915 МГц

## Необхідні компоненти
- Модуль LoRa
- Макетна плата розміром 20 × 80 мм
- 12-контактний гніздовий роз'єм (мама, якщо у Ваша Лілка зібрана як у мене)
- тонкий мідний провід
- керамічний конденсатор 0,2-0,5 мкФ (необовʼязково)

## Підключення
| Lilka J2 # | Lilka pin | LoRa pin |
|------------|-----------|----------|
| 1          | GND       | GND      |
| 2          | 3V3       | VCC      |
| 3          | RX (44)   | DIO1     |
| 4          | TX (43)   | BUSY     |
| 5          | 48        | NRST     |
| 6          | 47        | MISO     |
| 7          | 21        | MOSI     |
| 8          | 14        | SCK      |
| 9          | 13        | NSS      |
| 10         | 12        | RXEN     |
| 11         | 3V3       |          |
| 12         | GND       |          |

Додатково з'єднайте контакт **TXEN** модуля LoRa з його контактом **DIO2**.
За бажанням припаяйте конденсатор між лініями GND і VCC поруч із модулем.

## Збирання
Гніздовий роз'єм і модуль LoRa потрібно вирівняти так, щоб забезпечити надійне з'єднання під час підключення до Lilka.
Через велику кількість дротів, що перетинаються, використовуйте обидві сторони макетної плати для їх прокладання.
Орієнтацію 12-контактного роз'єму можна змінити, але враховуйте, що для більшості антен LoRa робочою є вертикальна орієнтація.
