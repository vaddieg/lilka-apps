# Bruce firmware for Lilka

## Compatibility
Bruce is compatible with Lilka built-in wi-fi, bluetooth, and SD card reader. 
Additionally, you can use Lilka's IR, SX126x, and CC1101 radio modules. See the **hardware** directory.

## Official repository
https://github.com/BruceDevices/firmware

## Lilka port
Lilka board support has been merged into the official BruceDevices/firmware repository and will be supported in 1.16.1+ releases
