# Bruce firmware for Lilka

## Compatibility
Bruce is compatible with Lilka built-in wi-fi, bluetooth, USB, and SD card reader. 
Additionally, you can use Lilka's IR, SX126x, and CC1101 radio modules. See the **hardware** directory.

## Official repository
https://github.com/BruceDevices/firmware

## Lilka port
Lilka board is officially supported by the official BruceDevices/firmware since the 1.17 release
